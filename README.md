# Hospital Appointment API

Node.js + TypeScript + Prisma CRUD module for a hospital appointment system.

## Models

- Patient
- Doctor
- Appointment

## Features

- Patient CRUD
- Doctor CRUD
- Appointment CRUD
- Prisma relations using connect
- Nested data using include
- Database seeding
- TypeScript test script

## Commands

### Seed database

```bash
npx prisma db seed
